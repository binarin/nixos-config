- modules/clan/forgejo-runner.nix already registers runners with --name
  nix-builder-raum / nix-builder-valak (with numeric suffixes after instance 1).
- Current evaluated packages: forgejo-runner 13.1.0, Forgejo server 16.0.4.
- Upstream runner v13.1.0 internal/app/cmd/daemon.go passes the connection UUID
  to createRunner, which passes it to run.NewRunner as the runner name.

  Runner %s (version:%s) received task ...
- Consequently job logs display Runner <UUID> independently of the hostname-based
  name registered on the server. Declare sends labels/version, not a new name.
- Sources checked through upstream HTTP endpoints, not /nix/store sources.

  the UI runner list. Registration is not the issue. No code change needed
  unless hostname-based job logging is desired.
