#+title: SSH trust policy extraction (tracker: SL-0001)
Design, decisions and acceptance criteria live in tracker ticket SL-0001.

* Status
- [X] Registry, trust roles and NixOS/system-manager policy in common
  (=modules/ssh-trust=, =lib.sshTrust=, =modules.{nixos,systemManager}.ssh-trust=).
- [X] nixos-config consumes common: =inventory/public-keys.nix= and
  =modules/public-keys.nix= removed; machine/account grants in
  =swanLake.sshTrust.accounts=; Ansible YAML projected from common plus
  =inventory/ansible-ssh-grants.nix=.
- [X] Effective before/after snapshot of every nixosConfiguration and
  systemConfig compared (keys by identity, principals, CA file, Forgejo CA).
- [ ] Paired common/nixos-config MRs; temporary common pin.
- [X] Signing CLI in common (=tools/ssh-ca=); =nix run .#ssh-ca -- session|sign ...=
  runs it with this flake's manifest (=.#ssh-trust-manifest=).
- [ ] Hardware smoke tests (YubiKey resident key, =--yubikey-serial=, Trezor agent).

* Effective changes from the extraction
- Termius keys retired everywhere.
- =hsm-tz= (was trezor-root-pve) becomes a user CA; =hsm-tz-ca= (was
  trezor-trusted-user-ca) becomes a direct-login key where Clan's
  all-secure selection did not already install it.
- Every covered account accepts =MACHINE--ACCOUNT= in addition to its
  preserved shared principals.
- ISO =nixos= installer account now gets the trusted HSM login keys
  (normal login account coverage).

- PKCS#11 Proxmox keys no longer on root of every Clan machine (that came
  from the old "every secure key" selection by accident); they stay on the
  Proxmox hosts through the Ansible grants.

* Coverage opt-outs
- =protonmail-bridge= (mail), =ssm-user= (xray-front), =annex= (media;
  forced-command key/principal only), =nix-remote-builder= and =paperless=
  (explicit restricted grants).

* Deliberately unchanged during the migration
- =scripts/sign-ssh-key.sh= (still signs =binarin,root= by default).
