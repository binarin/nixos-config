** Usage
- Build: nix build .#configured-pkgs.x86_64-linux.nixpkgs.pi-with-extensions.
- Build extension resources by replacing pi-with-extensions with pi-claude-bridge or pi-subagents in that attribute path.
- Authenticate with claude auth login, then select a claude-bridge/... model in Pi's /model menu.
- Existing mutable Pi settings are untouched. The user's provider.pathToClaudeCodeExecutable in ~/.pi/agent/claude-bridge.json still overrides the Nix default.
