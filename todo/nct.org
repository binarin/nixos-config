#+TITLE: nct (nixos-config-tool)

* Goal

Scaffold a new Rust-based CLI tool =nct= (executable =nct=) to eventually
assist with NixOS configuration management in this repo. Companion / eventual
successor-ish to the Python-based =ncf= tool, but starting from a minimal
scaffold.

* Stage 0 — scaffold [DONE]

** Decisions
- Async-first: =tokio= (full) pulled in from the start; =main= is
  =#[tokio::main]=.
- =nct= lives in the default devshell (like =ncf=) so it's on PATH in the main
  shell, in addition to its dedicated =.#devShells.x86_64-linux.nct=.
- No new flake inputs were added, so =nix run .#write-flake= was **not**
  needed (=flake.nix= untouched).
- Used =selfLib.dir'= / =file'= for src + cargoLock (avoids flake-source
  leakage, consistent with =niri-dynamic-keybindings= / =waybar-org-clock=).
