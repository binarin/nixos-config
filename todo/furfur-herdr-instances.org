** tmux-prefix + last-tab (2026-11-10)
- tmux-prefix vendored from herdrdev/herdr-layout-examples@ed4eda7a (Apache-2.0), with changes noted in its header.
- Matches modules/binarin/tmux.nix rather than the request's wording: C-o C-o = last tab (bind-key C-o last-window), C-o o = literal ^O (bind-key o send-prefix).
  Added pain-control keys (| \ - _ splits, C-h/j/k/l), & , $ ( ) : s b. No resize (H/J/K/L): Herdr has no pane-resize command (#117).
- keys.json: global+terminal "ctrl-o": "mod.open:tmux-prefix"; "mod:tmux-prefix" "ctrl-o": "tmux-prefix.last-tab" (a second C-o reaches the open popup as a command).
- last-tab: a kept 2x2 frameless window overlay (key last-tab-tracker). It records focused().tab on render and every 500 ms into shared "last-tab.history" (most recent first, 30 ids).
  tmux-prefix opens it when globalThis.__herdrLastTabBeat is older than 2 s, so history starts at the first Ctrl-o after install. Kept windows reopen on start; a layout switch closes them until that layout shows again.
- herdr-app check writes jsconfig.json/gpui-kit.d.ts into the checked folder: files/herdr-app/mods/.gitignore ignores them.
** Findings
- Native sequences: the first key waits 1 s, then goes to the terminal (upstream #72; the key_timeout PR was closed in favour of mods).
- Upstream's prefix example: herdrdev/herdr-layout-examples/tmux-prefix (popup hint, no timeout, 500 ms repeat for hjkl/JK, sends literal prefix via hc). Has no last-window.
- Last tab: shihyuho/herdr-recall (MIT) has recall.previous-tab across spaces, inside a large fuzzy switcher.
  ohneda/herdr-last-pane does last *pane* (per space) with a floating layout block and a 300 ms focused() poll.
