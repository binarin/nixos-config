#+title: One nixpkgs evaluation, shared with common

* Goal (2026-11-09)
Stop evaluating/configure nixpkgs in nixos-config: reuse common's
=configured-pkgs= and append only this repo's overlays.

* What was done
common (=b7684e8=):
- generate =configured-pkgs= for =aarch64-linux= as well (nixos-config
  publishes flake packages for both systems),
- add =nixpkgs-unstable-cuda= (llm-runner's CUDA stack),
- move =oraclejdk.accept_license= and the version-pinned
  =permittedInsecurePackages= into the shared nixpkgs config, so reused sets
  keep the same packages.

nixos-config:
- =modules/nix.nix=: =nixpkgsConfig=, =importNixpkgs=, =flake.configured-pkgs=
  and =flake.lib.importNixpkgs= are gone. =flake.lib.pkgsFor system= is
  common's set + =nixosOverlays= + the =bleeding= / =trezor-agent= /
  =bleeding-cuda= aliases; =flake.lib.nixpkgs= is the x86_64-linux one.
  =perSystem= uses it.
- machines, =templates/clan-machine.nix=, =clan.pkgsForSystem= and deploy use
  =self.lib.nixpkgs= / =self.lib.pkgsFor=. The =nixpkgs.pkgs= pinning and
  =readOnlyPkgs= stay, so the shared-evaluation guarantees do not change.
- bubuntu (=murmur=) got the same missing =local-checkout-links= fix bentos
  needed: common's home module is in its =home-manager.sharedModules=.

  eight packages for x86_64-linux and aarch64-linux are identical to the
  pre-change snapshots: the shared evaluation yields the same package sets as
  the old local one.
